从零到第一首歌

  1. 部署 Go 主服务。打开 /admin/，首次使用 admin/admin 登录并修改密码。
  2. 设置可达地址。在另一台设备上打开 NAS 的 /downloads/，确认局域网路由与端口可用。
  3. 添加少量测试歌曲。先选一个本地子目录或 WebDAV 子目录，保存并扫描，核对歌名、歌手和文件。
  4. 确认实际能播放。在目标电视或手机试播，核对原唱、伴奏和歌词；需要转码时再接入计算节点。
  5. 安装并连接电视。用手机 App 扫码登录或手动填写 NAS 地址。电视显示的是自己的家庭曲库。
  6. 邀请亲友。扫描电视上的“手机点歌”邀请，填昵称加入；新版组合中首首入队自动开唱。
  7. 再逐步扩大曲库。配置文件名方案、审核资料、收藏、歌单及定时扫描，最后安排配套备份。

系统如何组成

Go 是唯一业务主服务，维护账号、曲库、收藏、歌单、聚会队列、播放记录和任务。管理网页、亲友 H5 与客户端下载页由同一个 Go 服务托管；电视和手机负责实际播放，手机还负责本机录音。Python 计算节点按需承担媒体探测、转码和音轨处理。

数据保存与使用原则

  • 自备媒体。SingVerse 不提供中央歌曲内容；来源目录和媒体权限由部署者维护。
  • 原件只读。扫描、资料整理、伴奏生成和兼容转码不改写原始曲库。下载功能只向单独指定的可写目录发布新文件。
  • 资料与文件分开。歌名、歌手、封面、歌词等正式资料独立保存，人工订正不会因普通重扫被整体撤销。
  • 服务端统一状态。家庭收藏、公平队列与统计以 Go 为准；网络失败时不会用本地假数据冒充成功。
  • 增强能力按需启用。外部音乐平台、AI、搜索与自备音源会访问相应服务；本地部署不等于所有功能完全离线。
  • 验证有范围。本地构建、模拟器和受控数据检查不代替真实 NAS、微信、硬件 TV、蓝牙音频或 GPU 验收。

完整阅读路线

曲库准备：来源与扫描 → 文件名识别 → 信息审核 → 原唱与伴奏。家庭使用：收藏与歌单 → 电视 → 手机 → 亲友。运行维护：任务中心 → 计算节点 → 缓存与设置 → 账号安全 → 备份升级。
