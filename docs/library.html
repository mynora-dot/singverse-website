歌曲来源与曲库

把现有本地目录或 WebDAV 变成可搜索的家庭曲库。先确认服务可见的真实路径，再扫描、核对资料并逐步整理版本。

内容核对：2026-11-15基于当前源码 · 功能以部署版本为准
本页内容

添加本地目录

  1. 进入“加歌 → 歌曲来源”，点击添加媒体库并选择“本地目录”。
  2. 在目录选择器中浏览后端可见的目录，或直接输入绝对路径。
  3. 点击“使用当前文件夹”确认，名称留空时按文件夹名生成。
  4. 选择文件名识别方案，默认“保存并扫描”。

Docker 中只能选择容器内路径。宿主 NAS 目录必须先只读挂载，参见挂载歌曲目录。选择器不会浏览你的电脑，也不会自动修改权限。

添加 WebDAV

  1. 选择“添加 WebDAV”，填写名称和 HTTP(S) 目录地址。
  2. 按需填写用户名和密码或应用密码；不接受 URL 内嵌凭据。
  3. 选择解析方案，默认“保存并扫描”，也可仅保存后手动扫描。

地址需从 Go 服务所在网络可达，例如 https://nas.example/dav/歌曲目录/。OpenList 账号需开启 WebDAV 读取权限，不需要管理或删除权限。密码使用主密钥加密保存，页面不会回显明文。

  • 建议使用 HTTPS；没有关闭证书验证的开关。
  • 重定向不会自动跟随，请填写最终地址。
  • 改变地址或用户名且已有密码时，需重新输入或明确清除旧密码。

扫描与索引

扫描按来源建立文件名索引，重复扫描不会重复入库。扫描失败、目录离线或突然空库时会保留旧索引，避免把空挂载当作全删。

来源扫描方式主要边界
本地目录有界同步扫描，可后台入库单次上限 2000 个媒体文件、20000 个访问条目、32 层目录
WebDAV后台任务，页面可离开单来源最多 100000 首媒体，最长两小时；提交索引阶段不能取消

来源支持定时扫描，使用标准五段 cron（上海时区）。同来源扫描中会跳过触发，停机遗漏不逐次补跑。扫描期间不要修改来源或解析配置，否则需要重新扫描。

文件名识别

日常主路径是“加歌 → 歌曲来源 → 文件名识别”，按四步组织：

  1. 填文件名。输入一个真实媒体文件名，点击“找出能识别的格式”。
  2. 挑格式。在格式卡片中选择能完整识别的格式，点一下加入方案，再点移出。
  3. 保存方案。填写方案名称并保存。
  4. 高级配置。需要自定义顺序、启停或自定义格式时，展开高级配置。

选择方案后必须点“使用此方案并返回”，再保存来源才会变更绑定。共享方案会影响所有引用来源的后续扫描；只想调整一个来源时，先复制方案。未匹配的歌曲仍会保存为待复核记录。

元数据审核

“整理 → 歌曲信息”统一匹配与审核入口。完整流程见 歌曲信息与审核。可以从网易云、QQ、酷狗、酷我、汽水等平台匹配候选，逐字段确认后应用。

  • 新安装默认启用五个平台，自动应用默认关闭，匹配阈值默认 80%。
  • 审核区分当前值、候选值和草稿；先保存草稿，再明确确认应用。
  • 人工确认字段优先，重扫不会撤销人工决定。
  • 封面可选择原图或高清，显示实际像素，随确认保存。
  • 批量刮削受平台请求间隔和限流冷却约束，失败项可稍后重试。

平台设置位于“设置 → 音乐平台”。随机等待用于平滑流量，不能保证避免限流或自动化识别。

共享歌单

“曲库 → 歌单”支持手动选歌、排序、编辑和删除，也可用已配置启用的模型辅助创建。AI 最多从 500 首候选中推荐 1～50 首，先预览并明确采用，再保存。没有模型时仍可手动创建。歌单上限 500 首，电视端按保存顺序浏览。

共享收藏

“曲库 → 收藏”是后台、手机、电视与新版亲友 H5 共用的 NAS 集合。支持搜索、筛选、排序、曲库多选添加、单首取消和当前页批量取消。取消只删除收藏关系，不删除歌曲文件。已移除歌曲保留辨认信息，但不能播放。

支持的媒体格式

类型扩展名
视频MKV、MP4、MPG、MPEG、AVI、TS、VOB、MOV、WMV
音频MP3、FLAC、WAV、M4A、AAC、OGG、OGA、Opus、WMA、AIF、AIFF、APE

扩展名不区分大小写。能入库不代表浏览器或电视一定能解码；WMA、APE 等通常需要兼容播放或离线版本。新增格式需要重新扫描才会进入歌曲列表。

整理与分享边界

  • 移除来源只删除配置和索引，绝不删除原件或向远端发送 DELETE。
  • WebDAV 缺失文件需间隔至少 30 分钟的两次完整成功扫描确认下架。
  • 资料包按每片最多 5000 条歌曲记录与 32 MiB 预算拆分；完整上传最多 8 GiB，本机人工订正受保护。
  • 分类、歌手和封面更新后，电视约 30 秒同步或手动刷新可见。

歌曲、歌手、分类与版本

“曲库 → 歌曲”集中浏览所有来源，默认封面模式，可切列表；按来源、分类标签、文件名识别状态和关键词缩小范围。歌曲与版本资料、按文件管理是不同视角，失联文件不等于正式歌曲资料应被删除。

歌曲详情可查看歌词、分类、音轨状态和试听；歌手页使用已保存的真实肖像，无图显示占位。分类包含语种、年代、风格、情绪、场景和自定义标签，手动管理不依赖 AI。

“待复核”通常描述文件名解析，而资料已确认描述正式字段。对一个状态的处理不会自动消除另一个状态的历史证据。

定时扫描的填写与执行

在来源的“更多设置”开启，填写标准五段 cron，固定按上海时区（Asia/Shanghai）执行：

# 分 时 日 月 周
0 3 * * *        # 每天 03:00
*/30 * * * *     # 每半小时
0 3 * * MON-FRI  # 工作日 03:00

不接受秒、年、Quartz 特殊符号或 @daily 宏。调度约每 10 秒检查，实际开始可能更晚；同来源正在扫描或队列满时本次跳过，下一次按计划再尝试。

重启后过期计划只尝试一次，不按停机遗漏次数逐次补跑。禁用计划不会强制取消已开始扫描，也不会唤醒已停止容器。

扫描失败时怎样保护曲库

  • 读取失败、超限、取消、配置变化或突然空扫描时保留旧索引，不提交半批结果。
  • WebDAV 目录扫描主要使用 PROPFIND，不为了遍历而下载全部原媒体；实际播放会另外读取文件。
  • 来源“已配置”只代表配置存在，不保证持续在线，目录可读也不保证每首能解码。
  • WebDAV 同路径内容被替换时，需重扫更新可用属性；远端不提供大小或时间时，无法仅据这些属性识别变化。
  • 移除来源解除文件位置与索引关系，正式资料继续保留；原件不删除。
