存储、外观与 AI 设置

管理 NAS 缓存、电视首页和可选 AI 服务。理解共享容量、保护规则、配置保存位置与每项增强能力的实际边界。

内容核对：2026-11-15基于当前源码 · 功能以部署版本为准
本页内容

管理端入口名称可能随版本略有调整。请以实际部署的“设置”“计算与模型”“存储与缓存”“客厅”页面为准。

计算节点

计算节点是可选的 Python 服务，负责媒体探测、内嵌标签读取、兼容转码、音轨分析和伴奏分离等重任务。Go 主服务负责编排、鉴权、队列和结果落盘；电视、手机、亲友 H5 和管理浏览器都不直接访问计算节点。

模式适用场景行为
自动识别同一部署组合已提供计算服务读取部署变量并测试内部连接与回源地址。
独立部署计算节点在另一台机器或容器填写节点地址和内部凭据，测试通过后保存；凭据不回显。
暂不使用只使用文件名索引和可直放媒体停用新转码、分离和探测任务，已有缓存仍可管理。

配置步骤

  1. 进入“设置 → 计算与模型”或性能节点页面，选择连接模式。
  2. 独立部署时填写计算节点可达地址和内部认证信息；地址必须能从 Go 服务访问。
  3. 执行连接测试。测试会检查节点身份、内部认证，以及节点回到 Go 服务的回调链路。
  4. 测试通过后保存。失败时保留原设置，不会静默切换到不可用节点。
  5. 在歌曲播放、原唱与伴奏或元数据任务中按需使用计算能力。

局域网发现与配对

管理端可在受限私网范围内发现计算节点，并通过发现结果配对。配对不接受浏览器随意指定节点地址或凭据；节点需开启局域网配对，已绑定节点只允许相同身份恢复。发现记录短期有效，配对失败保留当前连接和草稿。

硬件与模型

  • 页面只显示实际检测到的加速硬件和必要的 CPU 降级配置，不承诺所有机器都有 GPU 加速。
  • 伴奏模型可通过固定清单下载、受控导入、试跑和选择；上传大小和模型类型有上限。
  • 分离配方可选择极速、干净或旧版高级路线；不同配方和输出格式会隔离缓存。
  • 计算节点重启后，未完成的执行会标记失败，不会冒充已完成结果。

计算节点离线时，已有缓存仍可读取和管理，但新的兼容转码、音轨分析和伴奏分离无法执行。原始媒体始终只读。

AI 设置

AI 设置分为“模型服务”“搜索服务”“功能配置”三个页签。服务配置和功能绑定分开管理，便于多个功能复用同一厂商，也便于单独停用某个能力。

  • 模型服务：配置厂商、模型 ID、密钥和结构化输出方式。模型 ID 手填，Schema 或 JSON 模式显式选择。
  • 搜索服务：配置可用于辅助查询的搜索能力。测试结果只展示标题、链接、摘要和耗时，不抓取正文，也不用于分类。
  • 功能配置：把已保存服务绑定到分类或默认搜索等支持的功能，控制启用与间隔；歌单辅助在歌单编辑器选择模型。

使用边界

  1. 先保存服务，再执行测试；测试只请求已保存配置。
  2. 密钥只写不读，接口和页面不会回显明文密钥。
  3. 被功能引用的服务不能直接删除或停用，需先调整绑定。
  4. 未配置 AI 时，手动曲库管理、点歌和播放仍可使用。

启用外部模型、搜索或元数据平台前，请确认对应服务条款和网络可达性。自动平台写入默认关闭，人工确认优先于自动证据。

缓存管理

“设置 → 存储与缓存”展示 NAS 上保存的 WebDAV 原片块和完整音视频兼容结果。缓存用于减少回源和重复转码，不等同于原始媒体，也不等同于独立保存的离线兼容版本。

容量与策略

  • 默认预算为 50 GiB。尚未手动保存设置时，每次启动会检测缓存目录所在磁盘可用空间；空间不足时使用剩余空间的 80%。
  • 手动保存后，重启保留已保存容量。手动容量范围为 64 MiB 到 1 PiB。
  • 策略可选混合评分 HYBRID 或手动 MANUAL。混合评分结合真实播放热度、最近活动和近 7 天有效频次。
  • 高/低水位默认 90% / 75%，要求低水位小于高水位；磁盘最低保留空间独立生效。

固定与保护

  • 固定按歌曲生效，覆盖同曲现有及未来原片/HLS 变体；固定不强制下载整曲，也不变成离线成品。
  • 正在播放、正在下载、固定歌曲和近 24 小时实际播放受保护。暂停、缓冲和预取不刷新实际播放保护。
  • 单份删除须先取消固定；近期保护需要明确确认，活动播放/下载保护不可绕过。
  • 清理全部和按策略回收在后台执行（手动策略不能执行按混合策略回收），可显示等待、进行、取消、部分失败和保护阻塞；重新进入页面可恢复未完成任务。

清空缓存不会删除原始媒体、正式歌曲资料或持久附件。计算节点离线时，仍可管理已有缓存。

电视首页

“客厅 → 电视首页”提供即时预览，用于配置所有登录同一 NAS 的电视共用首页。内置默认封面随 Go 服务发布，不依赖外部图床。

项目限制或行为
封面数量最多 8 张 JPEG/PNG。
单张图片不超过 2,000,000 字节，边长不超过 4096 像素；保存时归一为最长边 1280px 的 JPEG。
标题与说明标题最长 80 字符，说明最长 160 字符。
轮播可开关，间隔 5～60 秒。
精选歌单最多展示 4 个已保存共享歌单。

保存与同步

  1. 上传封面即保存并启用；移除、排序和启停按页面提示保存。
  2. 标题、说明和轮播草稿需点击保存；有草稿时先保存再上传或移除图片。
  3. 版本冲突会提示，不会静默覆盖其他管理员的修改。
  4. 电视端约 30 秒同步一次，也可手动刷新。亲友参与身份不能读取首页配置图片。

备份与升级

升级前先做停机备份。数据库、主密钥和计算节点认证必须配套保存；只备份数据库而丢失主密钥，可能无法恢复加密凭据。

备份清单

内容说明
业务数据库与持久资料SQLite/MySQL 数据、正式附件和业务衍生文件。
主密钥保护 WebDAV、AI、节点认证等加密凭据，须与数据库同版本配套。
计算节点认证与设置独立计算节点的身份、认证和硬件设置。
下载与缓存卷下载卷保存实际歌曲，应纳入备份；歌曲缓存可按策略重建，计算 cache 卷内的设置需保留。
外部媒体NAS 原曲库和 WebDAV 远端按各自存储策略备份，SingVerse 不修改原件。

升级步骤

  1. 停止业务服务，完成数据库、密钥和持久卷备份。
  2. 源码路线更新完整同版本源码后，使用原组合执行构建和启动；镜像路线固定新版本后拉取并启动。
  3. 保留现有命名卷和本地配置，不任意删除数据卷。
  4. 确认健康检查、登录、亲友 H5、播放和计算功能后结束维护。

旧镜像不一定能读取新迁移后的数据库。回退需要恢复匹配的数据和密钥备份，不能直接把新数据库交给旧镜像。

读懂缓存的容量与份数

同一首歌可以有原片块和不同画质、音轨、字幕的兼容结果，因此“缓存份数”不等于歌曲数。原片可能只有头尾或部分区间，只有完整状态才表示整曲字节已缓存。

占用还可能包括正在接收与待清理残留；预留字节单独展示。目录实际占用与列表已发布条目的合计可能不同，不能直接当作漏记。

原片块与兼容结果共享容量。缓存不足时会跳过新增缓存或继续回源/使用当前计算产物，不把容量预算等同于原曲无法播放。独立离线兼容版本不由这项预算自动淘汰。

按策略回收、清理全部与保护

  • HYBRID 达高水位后按混合评分回收到低水位，容量已在目标以下时不保证释放大量空间。
  • MANUAL 不自动淘汰，也不能用“按策略回收”临时执行混合回收；可按界面清理允许的副本。
  • 固定按歌曲覆盖现有与未来缓存，但不强制下载整首；固定记录可以没有实际缓存。
  • 固定、正在播放/下载、有效预取及近 24 小时实播有保护，受保护内容可能使目标不可达。
  • 取消清理保留已完成删除，离页后台继续；部分完成、保护阻塞与失败分别查看。

分类与 AI 助手展示

“曲库 → 分类标签”维护语种、年代、风格、情绪、场景及自定义标签。AI 分类使用功能绑定的模型，结果仍需业务校验与按配置确认；普通生成测试成功不等于分类正确。

模型、搜索与音乐平台是不同设置。搜索服务测试只查询主动输入的关键词，不抓取正文，不会自动用于分类。外部请求失败不会静默切换协议或自动重试付费调用。

AI 助手当前提供入口、宠物/聊天框形态和展示偏好；对话与工具能力尚未开放。开启展示不自动绑定模型，不授予曲库读写工具，也不代表助手能代替管理员操作。

管理端与设备的外观偏好

管理网页提供浅色和深色主题，保存在当前浏览器，不随系统自动切换。手机标准/长辈模式、电视的音量与同步偏好各自在设备本机保存；电视首页内容则由 NAS 统一配置。
