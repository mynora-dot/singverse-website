文件名识别

先用真实文件名挑格式，再把完整方案绑定到歌曲来源。无需移动或重命名原文件，就能逐步整理歌名、歌手和版本。

什么时候需要文件名识别

入口为“加歌 → 文件名识别”，也可以从“歌曲来源”卡片或来源表单的“试验与调整”进入。识别把文件名中的歌名、歌手、版本等信息提取为入库证据，不会重命名媒体文件，也不会自动下载歌曲。

一个来源绑定一份完整方案；方案按顺序包含若干格式。扫描依次尝试启用格式，第一条完整命中生效。一个方案可以由多个来源共用，同一种格式也可能被多个方案引用。

第一步：准备真实文件名

  1. 从待导入目录复制一条完整文件名，保留分隔符、扩展名、版本词和括号。
  2. 在“填文件名”输入示例，点击“找出能识别的格式”。检测只在点击时请求，输入变化后旧结果会标为过期。
  3. 同时检查歌名与歌手，不要仅凭“匹配成功”就保存；现场版、合唱、伴奏等版本词也要核对。
示例命名（用于理解，不保证任一内置格式都匹配）：
歌手 - 歌名.mp4
歌手 - 歌名（现场版）.mkv
歌曲编号_歌手_歌名.flac

建议至少准备三种样本：常见文件、带版本标签的文件、命名不标准的文件。若某个来源混有多套命名，可在同一方案中加入多种格式。

第二步：挑选可用格式

格式卡片会区分“能用”“只认出一半”“识别不了”和“已在方案里”。点击卡片加入，再点击移出。结果来自当前示例的真实解析，并不代表整个来源的所有文件都能正确识别。

  • 优先使用能完整分出歌名与歌手的格式。
  • 相似格式并存时，在高级配置中确认顺序，避免宽泛格式抢先命中。
  • 更换示例后重新检测；旧检测结果不能直接当成新文件的结论。
  • 没有合适格式时，使用高级自定义配置，或让歌曲先作为待复核入库，再手工整理资料。

第三步：保存方案并绑定来源

  1. 填写方案名称，保存方案。
  2. 在来源弹窗中操作时，点击“使用此方案并返回”。
  3. 回到来源表单后，再保存来源，新的绑定才生效。
  4. 对该来源执行重新扫描，使后续解析使用已保存方案；保存方案不会立即重写已有歌曲列表。

保存共享方案会影响所有引用来源的后续扫描。如果只想调整一个文件夹，先复制方案，再绑定到该来源。复制方案不会同时复制其引用的自定义定义。

第四步：顺序、启停与自定义

展开“我要自己排顺序、启停，或用自定义格式”，可查看有序成员、逐项启停，加入已有自定义格式，再“解析当前方案”查看完整尝试过程。内置格式只读，需定制时先复制到自定义配置。

自定义入口位于文件名识别的高级配置内。新增或编辑时先编译校验，确认所需字段；不要把普通来源配置与自定义定义修改混为一次保存。共享定义的修改会影响所有引用它的方案。

  • 默认方案可以改名、调整甚至清空成员，但不能删除。
  • 已被来源引用的方案不能直接删除，需先改绑来源。
  • 已被方案引用的自定义定义不能删除，先处理引用。
  • 空方案或没有匹配结果时，歌曲仍可保存为需复核记录，不会偷偷换用其他方案兜底。

待复核与人工订正的关系

文件名“待复核”表示解析证据不完整，不等于文件损坏。到“曲库 → 歌曲”按识别状态筛选，点击“去复核”打开歌曲信息工作台，搜索候选或手工填写并确认。

正式资料与文件名解析状态分别保存。确认歌名或封面不一定改变文件名待复核标记；再次扫描也不会撤销已经保存的人工资料。查看时应区分“解析出了什么”和“最终确认了什么”。

未保存、冲突与扫描中的修改

切换、返回、关闭或刷新时会保护未保存输入。多人或多窗口同时编辑会发生版本冲突；先读取最新配置，再核对保留的草稿。修改示例、顺序或成员后，旧预览会失效。

扫描冻结开始时的方案快照。扫描中修改来源或解析配置，提交时可能因版本变化被拒绝并保留旧索引。应等当前扫描结束后修改，再重新扫描。
