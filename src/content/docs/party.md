## 扫描邀请并确认加入 {#join}

1. 电视首页显示本场“手机点歌”二维码，其他业务页可通过顶部入口打开邀请。
2. 亲友用微信或浏览器扫码，核对当前 NAS 与聚会信息。
3. 填写昵称并明确确认，才会加入；仅预览邀请不会创建参与身份。
4. 成功后进入点歌页面。手机底部为“点歌 / 已点 / 现场”，底部状态条可展开电视遥控。

参与凭据保存在本场 `sessionStorage`，不复用管理员 Cookie。离开本页面不会自动撤回已经点的歌；关闭标签、切换邀请或凭据失效后，可能需要重新加入。

这是聚会邀请码，与电视首次登录的 `singverse://tv-login` 码不同；首次登录码需要已登录的 Android 手机 App 扫描。

## 找歌、看详情与再点一首 {#request}

点歌页固定搜索，并提供分类、歌手、最近、热门、家庭收藏。分类包括已有语种、年代、风格、情绪、场景及自定义标签；歌手页使用 NAS 保存的肖像，缺图显示姓名占位。

1. 搜索歌名、歌手或支持的拼音关键词，也可从歌手、分类与家庭收藏浏览。
2. 打开详情核对歌手、版本、可用状态和封面。
3. 点歌后保留当前列表与滚动位置，歌曲行显示本人排队位置。
4. 需要再唱同一首可“再点”；网络结果未知时先核对队列，使用原请求重试。

最近与热门使用真实 NAS 播放历史，不会因刚点击点歌立刻增加次数。已经失联的历史歌曲仍可辨认，但不能再次点唱。

## 公平轮唱怎样排队 {#queue}

新版 FAIR 会话每人一首轮流唱，同一人的多首歌曲保留各自点歌顺序。新加入的点歌人进入当前轮转尾部；正在唱的歌不因后续操作被重排。

例如甲点了甲1、甲2，乙点了乙1、乙2，在甲、乙轮转时会依次唱甲1、乙1、甲2、乙2。界面顺序始终以服务端快照为准。

- **全部 / 我点的**：切换队列查看范围，不改变实际排序。
- **公平打乱**：只调整点歌人的轮转顺序，不打乱每个人自己歌曲的先后。
- **插队**：全场只有一个“下一首优先”位置，再次设置会替换前一个优先项。
- **取消插队**：恢复正常轮转；优先歌唱完后也继续未消费的正常轮转。
- **撤歌**：普通亲友撤回自己的待唱，主持人可撤回所有人的待唱。

公平模式不提供破坏个人先后顺序的逐曲上移、下移。所有有效加入者均可设置优先位和公平打乱。

## 自动开唱、切歌与停止 {#autoplay}

配套新版在空闲状态下，第一首入队即可自动开唱；自然播完或明确切歌，由 Go 统一推进下一首，避免电视与手机并发操作跳过两首。

手动停止会保留停止状态，此后新增点歌不会擅自重播，需要明确“开始”或“继续”。电视进程恢复与重新连接后也应核对状态，不把恢复连接当成自动开唱授权。

## 每位在场亲友都可遥控 {#remote}

新版会话允许所有有效亲友遥控电视；主持身份主要影响撤回其他人的歌曲。散场、清空、锁队、主持授权与撤销参与者仍由电视端管理，亲友不能访问系统管理页。

| 操作 | 条件与反馈 |
| --- | --- |
| 暂停 / 继续 / 开始 | 电视在线且状态允许；手动停止后明确开始 |
| 重唱 / 切歌 | 先二次确认，操作绑定打开确认框时那次播放 |
| 拖动进度 | 电视支持 SEEK 且有总时长；准备或缓冲阶段可能不可用 |
| 原唱 / 伴奏 | 电视支持音轨切换，歌曲有真实可用标记或版本 |
| 纠正原伴 | 先保存全库标记，再向当前电视申请应用 |

“已发送”和“电视已执行”是不同状态。媒体重建、定位或音轨切换完成后电视才确认执行；失败会显示原因。歌曲已经切换时，旧确认或迟到定位会被拒绝，避免影响下一首。

## 原唱和伴奏不对时 {#correction}

从详情或遥控点“原伴不对？纠正”。双音轨可一键对调，多音轨明确选择两条不同音频轨，视频轨不会列为角色候选。此操作修改当前 NAS 的共享标记。

保存成功但电视未应用时，保留“标记已保存”的结果，可独立重试应用；不要反复对调造成标签又变回去。新版电视应用时保留位置、暂停状态和同一次播放计数。

## 点赞、鼓掌与喝彩 {#reactions}

电视支持互动时，可发送点赞、鼓掌、喝彩。电视全屏透明动效约两秒，无音效；电视设置可关闭并持久保存。

互动只在当前演唱实例短期有效，切歌、重连或过期后不会补播。每人每秒最多 3 次、全场每秒最多 20 次，频繁点击会限流；互动不改变队列或播放次数。

## 家庭收藏与缺歌反馈 {#favorites}

点击心形加入或取消家庭收藏，修改的是所有家庭设备共用的 NAS 集合，不是浏览器私有收藏。服务失败保留原状态，不建立离线副本。

找不到歌曲时打开“反馈缺失歌曲”，填写歌名，按需补歌手、版本和说明。反馈进入管理端“客厅 → 缺歌心愿”，不会自动下载。提交超时保留相同内容和请求 ID，先核对再重试。

## 主持、锁队与离场 {#permissions}

- 普通亲友：点歌、自己撤歌、优先位、打乱、遥控、互动、家庭收藏和缺歌反馈。
- 主持人：额外可撤回其他人的待唱；授权由电视管理。
- 电视：锁队、解锁、清空、散场、主持授权与撤销参与者。
- 锁队、撤权和散场由服务端检查，过期页面不能绕过。
- 离场、换邀请会使在途请求和迟到响应失效；已提交的点歌不会因关网页自动消失。

## 连不上、旧电视或结果未知 {#troubleshooting}

1. 先在手机浏览器打开同一个 NAS 地址，确认不是 localhost、访客 Wi-Fi 或隔离网络。
2. 邀请失效时扫描电视刷新后的新码，避免反复使用旧截图。
3. 显示电视离线时，先恢复电视连接；命令“发送成功”不代表离线电视已执行。
4. 显示旧版本能力不足时，按 Go → TV → H5 顺序更新这一组协议组件。
5. 点歌超时先查看已点，保留同一请求重试；409 冲突先刷新当前状态再决定。
6. 微信、App 网页容器、软键盘和真实音视频链路需在目标设备验收。
