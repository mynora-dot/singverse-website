## 看一次操作，而不只看任务数 {#overview}

任务中心把扫描、媒体探测、音轨识别、资料匹配、下载或模型处理等操作按实际业务关联展示。一次扫描可带来多个后续任务，不能把“文件扫描完成”直接等同于“整批完成”。

## 状态如何理解 {#status}

| 状态含义 | 应做什么 |
| --- | --- |
| 排队 / 等待 | 查看资源、节点或前序阶段的等待原因 |
| 运行中 | 查看当前阶段与有依据的进度 |
| 待审核 | 资料候选已准备，仍需人工确认 |
| 部分完成 | 检查成功、失败、跳过的明细范围 |
| 失败 / 中断 / 取消 | 看原业务原因，修复后决定是否重试 |
| 已完成 | 确认具体产物，再按需要试听或播放 |

不同类型的进度单位不同，任务数不能直接换算成整个曲库完成百分比。未知总量时以阶段和已处理明细为准。

## 扫描后的处理链 {#scan-chain}

文件索引完成后，可能还在等待媒体探测、快速识别或对应判断。计算端暂不可用与未配置节点的行为不同，查看等待原因而不是不断重新扫同一来源。

## 刷新与重启 {#recovery}

关闭网页不会普遍取消后台任务。重启后按每种业务自己的规则恢复、暂停或标记中断；不能假定所有任务都会无损续跑。修改设置前先确认活动任务及实际支持的暂停/取消行为。

## 历史与故障记录 {#retention}

任务中心保留阶段和结果摘要，不是永久日志备份。结束批次有保留期限，关联歌曲或来源删除后也可能只剩快照。清理任务记录不等于删除歌曲和缓存。

反馈问题时提供任务类型、时间、镜像版本和脱敏错误信息，避免公开媒体地址、token 或 WebDAV 密码。
