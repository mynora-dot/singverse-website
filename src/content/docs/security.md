## 单管理员与首次改密 {#account}

当前为单管理员模式，没有家庭成员注册或独立个人账号体系。空库首次账号为 `admin/admin`；容器重建、普通迁移和重启不覆盖已经修改的账号或密码。

1. 登录管理端，进入“设置 → 账号与安全”。
2. 修改初始密码，新密码 15～128 个 Unicode 字符，可使用密码管理器与空格。
3. 按需修改登录账号；成功后所有会话撤销，使用新账号重新登录。
4. 按需启用 TOTP，并离线保存恢复码。

手机登录、管理员网页登录和电视设备是不同会话。电视拿到的是限权设备凭据，亲友拿到的是本场参与凭据；不要把管理员密码当作亲友邀请码。

## TOTP 二次验证与恢复码 {#mfa}

在账号页开始绑定，使用认证器扫描二维码或输入手动密钥，再以六位动态码确认。未在五分钟内确认的绑定不生效，重新绑定期间旧验证继续有效。

绑定或重新生成时提供 10 枚一次性恢复码，明文仅当次显示，需单独离线保存。恢复码用于密码之后的 MFA 验证，不能代替账号密码，也不是忘记密码页面的重置码。

改密、改账号、绑定确认、关闭 MFA 和重新生成恢复码都会撤销会话。切换设备登录前，确认仍持有认证器或未使用的恢复码。

## 记住密码与自动登录的区别 {#sessions}

| 选项 | 保存及有效期 |
| --- | --- |
| 网页记住密码 | 由浏览器密码管理器处理，应用存储只保存账号与偏好 |
| 普通会话 | 空闲 30 分钟或绝对 8 小时到期 |
| 自动登录 | 完整认证后服务端会话绝对 30 天，不跳过 MFA |
| 退出登录 | 撤销当前会话并关闭本浏览器自动登录偏好 |
| Android 手机记住密码 | 本机 Android Keystore 加密保存，切换 NAS 不复用旧凭据 |

HTTP 局域网页面可能不支持网页密码接口，应以浏览器自身保存提示为准。自动登录只是保持已验证会话，首页仍会向 Go 核验实际权限。

## 忘记密码，仍有 MFA {#password-reset}

1. 先在登录窗口打开“忘记密码”，查看与当前部署方式对应的命令。
2. 到部署主机，先停止业务进程，沿用相同数据库、密钥、环境与 Compose 配置。
3. 在交互终端运行 `singverse --issue-password-reset`（原生构建通常为 `bin/singverse`），输入要求的确认。
4. 启动主服务，在页面填写账号、一次性重置码和新密码。
5. 重置后用新密码及原 MFA 重新登录，所有旧会话会被撤销。

重置码有效 15 分钟，只能使用一次；重新生成会作废前一个码。该流程保留 MFA、账号和业务资料，不提供远程生成重置码的接口。

## 同时丢失认证器与恢复码 {#emergency}

需要部署主机上的紧急恢复 `--reset-admin`。必须先停止全部写入者，使用同一部署配置与真实交互 TTY，按提示输入确认和新密码；不要将密码写进命令参数、脚本或共享日志。

紧急恢复清除 MFA、恢复码及会话，保留其他业务数据。它不能修复丢失的主密钥，也不能解密失去匹配密钥的 WebDAV 或 AI 凭据。

## 局域网与 HTTPS 入口 {#network}

Docker 默认业务绑定回环，局域网访问需设置真实 LAN IP。公网或跨网络访问由外部反向代理提供 TLS，保留同源认证、会话与 CSRF。

```sh
# 示例：替换为自己的实际 HTTPS 根来源与真实代理地址
SINGVERSE_PUBLIC_ORIGIN=https://singverse.example.com
SINGVERSE_TRUSTED_PROXIES=192.168.1.10
```

仅信任真正的代理地址或 CIDR，保留原始 Host；外部代理处理证书、流式媒体、请求大小和限流。不要为处理证书错误关闭 TLS 校验。发现与二维码只是连接入口，不授予管理权限。

## 主密钥与加密配置 {#key}

主密钥保护 MFA、WebDAV、AI、自备音源及节点相关受保护配置。数据库已有密文而密钥缺失或不匹配时，服务会明确失败，不静默生成替代密钥。

Docker 使用独立 secrets 卷；原生可通过 `SINGVERSE_AUTH_KEY_FILE` 指定。备份数据库必须同时备份匹配密钥和正式资料目录；账号恢复不是密钥恢复。

## 哪些数据会离开 NAS {#privacy}

| 能力 | 可能发送的信息 |
| --- | --- |
| 平台资料匹配 | 歌名、歌手等查询关键词，读取候选资料与图片 |
| AI 分类 / 歌单辅助 | 当前功能需要的歌曲与分类描述；按所选服务发送 |
| 搜索服务测试 | 主动输入的关键词，返回标题、链接和摘要 |
| 自备下载音源 | 按音源执行受控目录与音频请求 |
| 可选独立计算节点 | 任务授权的媒体读取与处理输入 |
| 手机录唱作品 | 本机保存，当前不自动上传到 NAS 业务库 |

没有启用相应服务时，不依赖该项外部能力。诊断资料应隐藏真实凭据、邀请码、媒体路径和个人数据。客户端下载页免登录只读，不因此公开管理或曲库。

## 安全设置如何保存 {#backup}

业务设置随数据库备份，主密钥与持久附件需配套；浏览器主题、设备偏好与手机作品有各自的本机保存位置。详见 [备份、升级与维护](/docs/operations.html)。
