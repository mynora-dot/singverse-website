## 添加本地目录 {#local}

先确认 Compose 已把宿主曲库只读挂载到 `/media`。进入“加歌 → 歌曲来源”，新增本地来源，在文件夹选择器中选择容器内目录并确认。新增本地库通常从 `/media` 开始，下载用途使用 `/downloads`。

路径不存在时先检查 Docker 挂载，不要把宿主 `/volume1/music` 原样填进只看得到 `/media` 的容器。名称可留空自动生成，保存后先扫描小目录。

## 添加 WebDAV {#webdav}

选择 WebDAV 来源，填写真实地址与按服务要求提供的账号密码。保存后测试读取，再扫描目标目录。凭据由业务服务保护，不需要填入部署环境变量，也不交给电视或亲友浏览器。

401/403 先检查授权；连接失败检查 Go 容器到 WebDAV 的网络与证书；路径错误先核对根目录。访问失败不等于远端原片已删除，不用删库重扫解决网络故障。

## 扫描与识别 {#scan}

扫描建立文件与歌曲索引，不会自动保证歌名、歌手和原伴都正确。WebDAV 扫描为后台任务，可在来源与任务中心查看；完成文件扫描后可能继续媒体探测和快速音轨识别。

文件名格式不统一时，在来源内选择识别方案，先用真实样本预览，再保存来源。详见[文件名识别](/docs/filename.html)。每批扫描使用自己的配置快照，改规则后要明确安排后续扫描。

## 找歌与核对资料 {#browse}

“曲库 → 歌曲”可按来源、分类和识别状态筛选，再搜索歌名歌手。歌曲、实际文件和不同版本有各自身份；同名不代表同一素材。先试听，确认版本、时长和内容后再应用平台资料。

人工订正保存在正式资料层，重扫不能当作撤销订正的方法。资料与封面见[歌曲信息](/docs/metadata.html)，原唱/伴奏见[音轨指南](/docs/audio.html)。

## 定时扫描 {#schedule}

来源“更多设置”可启用五段 cron 计划，例如 `0 3 * * *` 表示每天 03:00，时区按页面配置核对。计划默认关闭；服务周期检查到期任务，不保证秒级开始。

同一来源正在扫描时不会为计划强行中断它。关闭计划不取消已开始的扫描，最终状态仍到任务或来源页面查看。主机离线、远端限流和访问失败需要分别处理。

## 来源与数据的边界 {#safety}

原始媒体保持只读，元数据、衍生伴奏和缓存保存在专门的数据目录。删除缓存不是删除歌曲，解除来源也不是替你删除原片。大规模移库、替换绑定目录或重新组织 WebDAV 前，先备份并用小范围验证。
