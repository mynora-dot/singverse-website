## 从零到第一首歌 {#first-song}

1. **部署 Go 主服务**。打开 `/admin/`，首次使用 `admin/admin` 登录并修改密码。
2. **设置可达地址**。在另一台设备上打开 NAS 的 `/downloads/`，确认局域网路由与端口可用。
3. **添加少量测试歌曲**。先选一个本地子目录或 WebDAV 子目录，保存并扫描，核对歌名、歌手和文件。
4. **确认实际能播放**。在目标电视或手机试播，核对原唱、伴奏和歌词；需要转码时再接入计算节点。
5. **安装并连接电视**。用手机 App 扫码登录或手动填写 NAS 地址。电视显示的是自己的家庭曲库。
6. **邀请亲友**。扫描电视上的“手机点歌”邀请，填昵称加入；新版组合中首首入队自动开唱。
7. **再逐步扩大曲库**。配置文件名方案、审核资料、收藏、歌单及定时扫描，最后安排配套备份。

## 系统如何组成 {#architecture}

Go 是唯一业务主服务，维护账号、曲库、收藏、歌单、聚会队列、播放记录和任务。管理网页、亲友 H5 与客户端下载页由同一个 Go 服务托管；电视和手机负责实际播放，手机还负责本机录音。Python 计算节点按需承担媒体探测、转码和音轨处理。

| 组成 | 主要用途 | 访问方式 |
| --- | --- | --- |
| NAS 管理网页 | 管理来源、资料、设备、任务和系统设置 | `/` 或 `/admin/` |
| Android TV | 大屏点歌、播放、聚会管理、互动展示 | Android 5.0+ 的 TV APK |
| Android 手机 | 连接曲库、练唱录音、作品、扫码登录电视 | Android 7.0+ 的手机 APK |
| 亲友 H5 | 点歌、家庭收藏、队列、电视遥控和互动 | 本场邀请打开 `/party/` |
| 客户端下载页 | 查看并下载安装包、版本和校验信息 | 免登录只读的 `/downloads/` |
| 可选计算节点 | 探测、兼容转码、音轨识别、伴奏生成 | 仅由 Go 连接，客户端不直连 |

## 不同身份能做什么 {#roles}

| 身份 | 典型操作 | 身份来源 |
| --- | --- | --- |
| 管理员 | 管理曲库、平台、计算、账号、备份及资料审核 | NAS 账号密码，按配置完成 MFA |
| 电视设备 | 访问家庭曲库，实际播放并管理聚会 | 登录后签发的独立设备凭据 |
| Android 手机 | 管理员会话访问曲库，本机播放与录唱 | 手机登录当前 NAS |
| 本场亲友 | 参与点歌、收藏、遥控、互动、缺歌反馈 | 确认当前聚会邀请后签发的本场凭据 |
| 未登录访客 | 查看欢迎页、邀请预览和客户端下载 | 没有管理或曲库权限 |

:::note
亲友不需要管理员账号。家庭收藏属于当前 NAS，录音作品属于当前手机；这两类数据的保存位置不同。
:::

## 哪些功能需要额外条件 {#capabilities}

| 能力 | 需要准备 | 未准备时 |
| --- | --- | --- |
| 搜索、文件名入库、点歌和可直放播放 | 可读媒体与可达 Go 服务 | 无需 AI 或计算节点 |
| 自动发现 NAS | 宿主发布 mDNS，网络允许组播 | 可手动输入 NAS 地址 |
| 首首自动开唱、进度遥控、公平轮唱、互动 | 配套的 Go、TV 与 H5 新版本 | 界面按旧 TV 能力限制操作 |
| 媒体探测、兼容转码、音轨识别 | 可用计算节点及双向回源链路 | 保留曲库，可播放兼容的原媒体或已有成品 |
| AI 伴奏分离 | 节点支持的运行库、模型与可用设备 | 仍可人工标记已有音轨 |
| AI 分类、歌单辅助 | 管理员配置并启用的模型服务 | 手动分类与手动歌单继续可用 |
| 下载歌曲 | 自备音源、可写本地目录及网络 | 不提供内置音源或中央曲库 |

## 数据保存与使用原则 {#principles}

- **自备媒体**。SingVerse 不提供中央歌曲内容；来源目录和媒体权限由部署者维护。
- **原件只读**。扫描、资料整理、伴奏生成和兼容转码不改写原始曲库。下载功能只向单独指定的可写目录发布新文件。
- **资料与文件分开**。歌名、歌手、封面、歌词等正式资料独立保存，人工订正不会因普通重扫被整体撤销。
- **服务端统一状态**。家庭收藏、公平队列与统计以 Go 为准；网络失败时不会用本地假数据冒充成功。
- **增强能力按需启用**。外部音乐平台、AI、搜索与自备音源会访问相应服务；本地部署不等于所有功能完全离线。
- **验证有范围**。本地构建、模拟器和受控数据检查不代替真实 NAS、微信、硬件 TV、蓝牙音频或 GPU 验收。
