# SingVerse 内容网站

独立的产品介绍与使用指南，使用 Vite 多页面静态构建。与 `singverse-frontend` 的管理端、亲友 H5、NAS 客户端下载页面是不同项目；更新本网站不会自动更新 NAS 服务或 APK。

当前内容核对日期为 **2026-11-15**，基于相邻仓库的实际工作区，包括尚未发布的实现。网站保留既有产品视觉，包含首页、客户端下载说明及 18 篇指南。各端能力以配套部署版本为准。

## 本地开发

Node.js 版本要求见 `package.json`，依赖由 `package-lock.json` 锁定。

```sh
npm ci
npm run dev
```

默认只监听 `127.0.0.1:5174`，端口占用时显式指定其他端口：

```sh
npm run dev -- --port 5184
```

## 检查与构建

```sh
npm run check:content
npm run check
npm run preview -- --port 5184
```

`check:content` 检查 HTML 标题与描述、共享模板展开、站内文件和锚点、章节 ID、侧栏入口以及生成搜索的目标。`check` 继续执行完整生产构建，产物为 `dist/`。检查只访问本网站的本地文件，不连接 NAS、不访问真实媒体或外部 API。

当前共有 20 个页面、18 篇文档、176 个文档章节与 200 个搜索入口。共享导航会在多页出现，站内链接检查包含这些重复入口。外部仓库链接未作在线可达性保证。

## 内容结构

| 分类 | 指南 |
| --- | --- |
| 入门 | 文档首页、部署与首次登录 |
| 曲库与整理 | 歌曲来源与曲库、文件名识别、歌曲信息与审核、原唱伴奏与歌词、下载歌曲与资料包 |
| 家庭开唱 | 家庭收藏与歌单、电视端、手机练唱与录音、亲友点歌与公平轮唱、播放热门与缺歌心愿 |
| 系统管理 | 任务中心、计算节点与兼容播放、存储外观与 AI 设置、账号安全与隐私、备份升级与维护 |
| 帮助 | 常见问题与排障 |

`docs/*.html` 是直接维护的文档源文件，新增 HTML 自动成为构建入口。共享顶栏、页脚和文档导航位于 `src/partials/`，页面使用 `{{root}}` 保持根目录与文档子目录相对部署可用。更新或新增页面时同时维护侧栏和上一篇/下一篇。

搜索不再维护单独的手写摘要列表。`scripts/content.mjs` 从页面 H1、描述、H2 与章节正文提取搜索索引，`vite.config.js` 通过虚拟模块交给前端；HTML 修改会刷新开发服务中的索引。新增文档需要明确的 H2 ID，原有深链接 ID 应保留。

下载说明页的表单只生成当前输入地址的 `/downloads/` 链接，不探测、保存或代理 NAS，不在本站托管 APK。

部署指南说明 GHCR、Docker Hub、阿里云 ACR 的 `IMAGE_PREFIX`、独立版本选择及 Compose 数据保留；维护指南说明发布者通过 GitHub Actions 参数选择镜像空间。官网不把示例空间或版本当作已经上线的镜像，实际地址以目标发布记录为准。

## 内容维护

事实依据与需要继续核验的边界见 [CONTENT_SOURCES.md](CONTENT_SOURCES.md)。更新时优先核对当前业务导航、权威契约、实际页面及设备实现。设计初稿、模拟数据和历史验证不能直接当作已发布功能或真机结果。

提交或推送本网站源码不会自动更新 NAS 服务；网站上线仍需将构建后的 `dist/` 部署到静态托管环境。
